# ことば島の大ぼうけん

小学生向けの、ブラウザで遊べるタイピング学習ゲームです。

小学1〜6年生の漢字を使った例文をローマ字で入力しながら島を探検します。正確さや速度に応じてスコアが増え、お宝を見つけたり、いきものと出会ったりします。iPadと外付けキーボードでの利用を主な対象としています。

**公開版:** [ことば島の大ぼうけんをプレイ](https://adventure-typing-9azkia6f2-ma38sus-projects.vercel.app/)

## 主な機能

- 1〜6年生、各6ステージを順番に解放する段階的な問題
- ホームポジション、指別キー、母音、左右交互入力、実用単語を扱うタイピング基礎ステージ
- 次に押すキー、左右の手、担当指、ホームポジションを示す指使いガイド
- 本編解放には影響しない数字・記号のオプション練習
- 漢字のルビと、小学校で学ぶヘボン式ローマ字の表示
- `shi / si`、`chi / ti`、文脈に応じた`n / nn`などの入力表記揺れ
- 正解位置、入力済みローマ字、間違えたキーの表示
- 苦手キー・得意キー・速度・正確さの記録
- 苦手キーを集中的に練習する復習モード
- ステージスコアと累積GP（がんばりポイント）
- お宝・いきもの・ステージ限定レア報酬の図鑑
- 複数ユーザーの端末内登録と進捗比較
- 問題・ステージごとの学習履歴
- 冒険者、歩行、休憩、発見などの演出、効果音、タイピング中の軽いBGM

## 画面遷移と進行

1. 起動時に、端末へ登録済みのユーザーを選択する。新規作成はこの画面の専用ボタンから行う。
2. 新規作成時に名前、学年、キャラクターを設定する。通常プレイのたびには聞き直さない。
3. ユーザー選択後、タイピング基礎を含むステージ選択画面へ進む。
4. 本編ステージは1から順番に解放する。クリア済みステージには何度でも再挑戦できる。
5. ステージを選ぶとタイピングを開始する。プレイ中の「ゲームを終了」でユーザー選択画面へ戻れる。

名前、学年、キャラクターは冒険者設定から後で変更できます。ユーザーを切り替えると、そのユーザーの設定、ステージ進捗、スコア、学習履歴、図鑑をまとめて読み込みます。

## 用語定義

| 用語 | 意味 |
|---|---|
| ステージ | 冒険する大きな場所。物語本編の土地や「タイピング基礎」が該当する |
| ルート | ステージ内で選ぶ挑戦経路。タイピング基礎では、指使いや学習目的ごとの練習単位を表す |
| 問題 | ルートまたは本編ステージ内で実際に入力する、個々のタイピング課題 |

タイピング基礎ステージには、ホームポジション、指別キー、母音、左右交互、実用単語、数字、記号のルートがあります。カード名は簡潔に「ホームポジション」などと表示し、画面の見出しでルート選択であることを示します。本編は現状、ステージから直接複数の問題へ進むため、不要なルート選択を追加しません。

## 技術構成

- Vite
- React 19
- TypeScript
- React Router
- Vitest
- Oxlint
- CSS

学習記録とユーザー情報はサーバーへ送信せず、ブラウザの`localStorage`へ自動保存します。手動セーブ操作はありません。プロフィールごとに記録を分離し、旧形式のデータも移行処理を通して読み込みます。

## 開発

Node.jsを用意して、依存関係をインストールします。

```bash
npm install
npm run dev
```

通常は `http://localhost:5173/` で開発画面を確認できます。

## 検証

```bash
npm test
npm run lint
npm run build
```

テストでは、ローマ字入力の表記揺れ、スコア、グレード境界、報酬抽選、プロフィール保存と移行処理を確認しています。

本番ビルドは`dist/`へ出力されます。

## 素材

- 配信用画像：`public/`
- 編集用の高解像度素材：`artwork/`
- 世界観・全36話・物語上の試練：[ストーリーバイブル](docs/story-bible.md)

## 作業開始時に読むもの

別セッションや別の担当者へ作業を引き継ぐ場合は、最初にこのREADMEと、作業内容に応じた以下の文書を最後まで読んでください。

### ストーリー・ステージ素材を制作する場合

1. [ストーリーバイブル](docs/story-bible.md)
2. [ゲームデザイン](docs/game-design.md)

世界観、登場人物、各話で起きる事件、物語上の試練はストーリーバイブルを正とします。タイピング体験、ステージ演出、UI、背景構図、素材制作仕様はゲームデザインを正とします。

背景や動物、アイテムを制作するときは、土地だけを見てランダムに割り当てず、対象となる学年・ステージ・前後の話・クライマックス試練を確認してから制作してください。

### 連続3D冒険シーンを制作する場合

上記のストーリーバイブルとゲームデザインに加えて、対象区間の制作ブリーフを最後まで読んでください。

- 草原から森: `docs/3d-scene-brief-meadow-to-forest.md`

制作ブリーフが存在する区間は、ブリーフ記載の基準画像、カメラ、ルート、植生、完成条件を優先します。いきなり全地域へ展開せず、一つの区間でグレーボックス、画面確認、品質版の順に承認してください。

### ストーリーやゲーム進行を実装する場合

上記2文書に加えて、以下の実装設定も確認してください。

- `src/game/storyConfig.ts`：ゲーム内で使用している全36話の文言と報酬ID
- `src/game/courseConfig.ts`：本編ステージ、背景、学年の設定
- `src/rewards.ts`：動物、アイテム、報酬ID

物語設定を変更した場合はストーリーバイブル、演出や仕組みを変更した場合はゲームデザインを先に更新し、実装との不一致を残さないようにしてください。

別セッションへは、原則として次の指示だけで引き継げます。

```text
作業前にREADME.mdを最後まで読み、そこに指定されたストーリー・ゲームデザイン文書と関連実装を確認してから進めてください。
```

## Vercelへの公開（推奨）

このアプリはVite製のSPAとして、そのままVercelへ公開できます。Next.jsへの移行は不要です。

`vercel.json`に全画面を`index.html`へ戻すSPAリライトを設定しているため、`/play`や`/collection`を直接開いた場合や再読み込みした場合もReact Routerが処理します。

VercelでGitリポジトリを読み込み、次の設定でデプロイします。

```text
Framework Preset: Vite
Build Command: npm run build
Output Directory: dist
```

ローカルでVercel CLIを使う場合は、プロジェクトルートで`vercel`を実行します。高解像度の編集素材がデプロイへ混ざらないよう、`.vercelignore`で`artwork/`を除外しています。

GitHub Actionsでは、`main`へのpushとPull Requestごとにテスト、lint、本番ビルドを実行します。

## 主なソース

```text
src/
  App.tsx                    画面とゲーム進行
  questions.ts              学年・ステージ別の問題
  romajiVariants.ts          ローマ字入力候補の生成
  kanaPractice.ts            指使い別の基礎教材と数字・記号練習
  KanaPracticePage.tsx       タイピング基礎ステージ
  scoring.ts                 スコア計算
  ranks.ts                   探検家グレード
  rewards.ts                 お宝・いきもの・抽選条件
  domain.ts                  共通データ型
  game/gameRunReducer.ts     タイピング中の一時状態と状態遷移
  game/useGameRunState.ts    reducer操作用のReactフック
  game/courseConfig.ts       学年・本編ステージ共通設定
  pages/                     タイトル・図鑑・問題一覧などの画面
  components/game/           入力・冒険演出・結果表示などの部品
  storage/profileStorage.ts  ローカル保存と移行処理
```

`App.tsx`はプロフィール、保存済み統計、ルーティングとゲーム進行を接続するコンテナです。タイピング中の一時状態は`gameRunReducer`、画面表示は`pages/`と`components/game/`へ分割しています。
