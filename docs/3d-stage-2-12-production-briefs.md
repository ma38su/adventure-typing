# Stage 2〜12 連続3D制作ブリーフ

最終更新: 2026-08-10
状態: 制作前の正本候補。グレーボックス承認前
対象: Stage 2〜12の空間、共有境界、イベント予兆、BGM意味区間

## 1. 共通指示

本書の各Stageは独立シーンではない。[Stage 1〜36対応表](3d-stage-1-36-continuous-world-plan.md) の同一`JourneyWorld`上へ、`worldProgress / regionId / chunkId`で配置する。Stage終了によるscene再生成、canvas再マウント、背景交換、再ロード、暗転、ポータル、クロスフェードは禁止する。

本書のStage 2〜12は、Stage 1の技術ゲート通過後に順番に実制作してよい範囲である。ただし十二Stageを同時着手せず、一境界ずつ六コマ承認を取る。Stage 13〜36は [将来制作ブリーフ](3d-stage-13-36-production-briefs.md) を資料として整備済みだが、Stage 12承認まで制作・実装を禁止する。

六コマは約10秒の固定動画を意味せず、確認再生で再現する正規化アンカーである。合格には構図だけでなく、直前コマから同じ空間を進んだと読めることが必要である。物語固有の動物、台詞、報酬本体はイベント接続前に焼き込まない。

全Stageの六コマは [景観anchorの地形リズム契約](3d-stage-1-36-continuous-world-plan.md#23-景観anchorの地形リズム契約) に従う。各コマを地域に合う異なるmicro-landformへ割り当て、制作データへ`microLandform / geologyReason / deltaFromPrevious`を記録する。前コマとの差は視界、勾配、水、岩、植生帯、landmark、光のうち最低二軸とし、二anchor連続で同じ状態を反復しない。既存六コマの必須画面・物語順・BGM意味区間は変えず、その成立根拠となる地形を選ぶ。

共通アート方向は「簡略化した日本画調 × 透明水彩 × 控えめなファンタジー」。強い黒輪郭、写真PBR、ネオン、球一個の樹冠、等間隔配置を避ける。

環境正本は [地学・気候設計](world-geology-and-climate-spec.md) と [植生・生物・文化設計](world-biomes-fauna-culture-spec.md) を併用する。世界は旧カルデラ縁を持つ古い低緯度玄武岩火山島で、東北東卓越風、北東多雨・南西雨陰、分水嶺からことば川へ集まる三支流を全Stageで維持する。低地林は亜熱帯常緑・半常緑林、山腹は雲霧林、尾根は風衝低木・草地、雲上は恒常雪でなく霧氷とする。入り江は河口湿地→海草藻場→白砂ポケット浜・外湾裾礁の順で、集落・建材・生業は地形へ適応させる。

球面座標から算出する`routeDistanceKm`を地図と3D worldの唯一の距離正本とする。空間短縮、途中skip、teleportをせず、chunk streamingで連続距離を扱う。見える前進速度を不自然に上げず、[全36対応表の距離別算定式](3d-stage-1-36-continuous-world-plan.md#22-距離から問題密度を決める契約)で18〜60問・可変courseを見積もり、各六コマ・発見・境界へ短文を配る。

## 2. Stage 2「小鳥が知っている道」— 森から山へ

### 物語と空間

- 目的: 重なった森の音からピピの知らせを選び、山へ向かう羽根印を得る。
- 開始ランドマーク: Stage 1終端と同じ森内部の細い木橋。両岸・対岸にも樹林が続く。
- 終了ランドマーク: 樹冠の切れ間にある低い石の星見門。山道はその先へ連続する。
- 近景: 苔の根、シダ、湿った岩、後半は乾いた草と低木。
- 中景: 小川、樹洞、羽根便の道標、疎らになる高木。
- 遠景: 木々の狭い抜けから灰青の山稜。海は見せない。
- 地形・植生: 湿った小川沿いから緩い上り。高木→若木→山地低木へ距離差を持って交代。
- 光・霧: 青緑の森光から夕金を含む灰青へ連続補間。標高上昇で霧を薄くする。
- 経路・カメラ: 橋を渡り、樹洞へ一度視線を寄せ、右へ蛇行しながら上る。高さは地形追従。道幅1.5〜1.8m。
- 共有境界: 開始は`evt-forest-creek-bridge`をStage 1と共有、終了は`bnd-forest-mountain-a`をStage 3と共有。
- 必要モデル: 既存forest一式、樹洞木、羽根便道標、山地低木、層状岩、星見門。
- 必要マテリアル: forest-floor、湿岩、乾いた土、灰青岩、夕金の草穂。
- アイテム予兆候補: 枝が順に揺れる、短い光の波、落ちた羽根印。報酬本体は2D。
- BGM意味区間: `forest-listen`（旋律を疎に）→`signal-found`（木管の短い応答）→`mountain-air`（低域を引き空間を開く）。曲を再起動しない。

## 3. Stage 3「星見の山の きらめき」— 山から入り江へ

### 物語と空間

- 目的: 渦巻く山風を分け、風に乗った二つ目の種を受け取る。
- 開始ランドマーク: Stage 2と共有する星見門。
- 終了ランドマーク: 谷川が湾北部の河口湿地へほどける手前の小さな石橋。白砂と珊瑚裾礁は岬の先でまだ見せない。
- 近景: 短い高原草、積み石、固定縄、後半は丸い河原石と耐塩草。
- 中景: 安全な山腹道、低い星見台、風見旗、谷川。
- 遠景: 序盤は山稜、見通し地点で初めて入り江と珊瑚色の海食岩。
- 地形・植生: 緩い登り→尾根の小さな開け→谷川沿いの長い下り。崖は奥側。
- 光・霧: 夕方の金から淡い珊瑚色の夕暮れへ。尾根では薄霧、谷で湿度を戻す。
- 経路・カメラ: 星見台へ視線を上げ、渦イベントでは横風ロールを微量、解決後は谷へ視線を下げる。落下感を出さない。
- 共有境界: `bnd-forest-mountain-a`→`bnd-mountain-inlet-a`。
- 必要モデル: 山地低木、岩3種、積み石、低い星見台、風見旗、結び縄、谷川リボン、河口石橋。
- 必要マテリアル: mountain-rock、dry-trail、highland-grass、stream-water、wet-pebble、dark-river-sand、reed-wetland。
- アイテム予兆候補: 風の中を横切る少数の光粒、地面へ落ちる星型の反射。
- BGM意味区間: `ridge-effort`→`wind-vortex`（持続音の不協和を少量）→`seed-descends`（高音倍音）→`sea-reveal`（波の呼吸を基礎拍へ）。

## 4. Stage 4「波が運んだ 小さな種」— 入り江から古代樹の根へ

### 物語と空間

- 目的: 潮の渦から貝と最後の種を岸へ戻す。
- 開始ランドマーク: 河口の小石橋、暗色砂、葦原。湾岸を進むと藻場、岬裏の白砂、外湾裾礁が順に現れる。
- 終了ランドマーク: 海食岩の奥で古代樹の根が自然に組む根門。
- 近景: 乾いた砂道、貝片、耐塩草、後半は湿った根と苔。
- 中景: 浅瀬、珊瑚礁、波食岩、短い木道、潮溜まり。
- 遠景: 沖の穏やかな島影。根門へ近づくと海面下に石造水路と根の形。
- 地形・植生: 河口湿地の木道→砂泥・海草藻場沿い→岬裏の乾いた白砂道→外湾裾礁の見通し→波食洞へ緩く内陸側へ曲がる。濁水と珊瑚を重ねない。
- 光・霧: 明るいターコイズから夕暮れ、洞内へ向けて月白と青緑。暗転させない。
- 経路・カメラ: 渦へ横視線を向けるが進路は岸上。成功後、波紋を追って根門へ。
- 共有境界: `bnd-mountain-inlet-a`→`bnd-inlet-root-a`。
- 必要モデル: 珊瑚大色面3種、波食岩、木道、潮溜まり、根アーチ、石造水路proxy。
- 必要マテリアル: dry-sand、wet-sand、shallow-water、coral、salt-rock、root-bark、moss。
- アイテム予兆候補: 波間の青緑光、同心波紋、貝殻近くの砂だけが反応。
- BGM意味区間: `shore-breath`→`tidal-knot`（低音を一時増加）→`return-to-shore`→`root-call`（木質の共鳴を薄く追加）。

## 5. Stage 5「月夜の森の めざめ」— 古代樹林から雲上へ

## 6. Stage 6「雲の上の 花まつり」— 雲上遺跡から草原へ

### 物語と空間

- 目的: 三つの種を花壇へ届け、仲間と乾いた花壇を回復する。直後、風だけが静まり次章へつなぐ。
- 開始ランドマーク: 上昇根と接続した花壇外縁。
- 終了ランドマーク: 風の階段が地上へ接する、草原の別の低い丘。
- 近景: 白石床、乾いた花壇、細い水路、開花後の低い花、下降路の風化石。
- 中景: 六角花壇、風除け柱、光の水路、風の階段。
- 遠景: 島の六地域、下降中の山稜と森、終盤の止まった小風車。
- 地形・植生: 平坦な遺跡庭園→外縁の緩い石段→尾根に沿う下降路→草原丘。奈落を進路へ置かない。
- 光・霧: 夜明けの空色・白・金。開花で彩度を上げるが、その後は風が止まり花びらが静止する。
- 経路・カメラ: 花壇周回はせず一方向。解決後、遠景を一度見渡し、風の階段へ連続して降りる。落下感を避ける。
- 共有境界: `bnd-root-sky-a`→`bnd-sky-meadow-a`。後者をStage 7と共有。
- 必要モデル: 六角花壇、水路、風除け柱、風の階段、風化石、草原小風車。
- 必要マテリアル: cloud-stone、dry-flowerbed、restored-flowerbed、light-water、weathered-stone、meadow-ground。
- アイテム予兆候補: 花壇の三つの柔光、仲間の作業を示す遠景シルエット、開花後に完成する光の地図。
- BGM意味区間: `dry-garden`→`friends-arrive`→`bloom`（完了ジングルを重ねる）→`wind-falls-still`（拍を止めず風ステムだけ引く）→`descent`。

## 8. Stage 8「森の風笛」— 風抜けの森から山へ

### 物語と空間

- 目的: 樹洞へ閉じ込められた風を正しい順序で通し、渡り便を再開する。
- 開始ランドマーク: 風笛が掛かる林縁。
- 終了ランドマーク: 風見台の基部が見える山峠。
- 近景: 揺れない葉、樹洞、枝道、落葉。解決後は葉群が順に揺れる。
- 中景: 樹上測定台、風穴のある特徴木、渡り便標識。
- 遠景: 再開する小鳥の便、山の風見台proxy。

## 13. アイテム発見演出へ渡す候補

空間グレーボックス承認後、最初は一種類だけ検証する。推奨はStage 2の「枝の順次揺れ＋小さな羽根印」である。地面の万能発光より物語と発見種別が伝わり、個別3Dアイテムを作らずに済む。

共通フローは、環境予兆→タイピング→予兆が一点へ集まる→2D報酬表示→環境へ結果を残す、の順とする。通常アイテム本体を常時3D配置しない。重要品も抽象予兆と2D表示で不足する場合だけ簡略シルエットを検討する。

## 14. BGM実装へ渡す意味イベント

3D側は楽曲名や小節を知らず、`musicZoneId`と0〜1の混合量だけを共有旅制御層へ出力する。音楽側は再生位置をseekせず、小節境界で予約したステム量へ滑らかに近づける。

```ts
type MusicMeaningState = {
  primaryZone: string
  secondaryZone?: string
  blend: number
  narrativeTension: number
  discoveryHint: number
}
```

- Stage終了でAudioContext、基礎ループ、拍位置を再起動しない。
- `typingPace`でBPM、再生速度、曲の進みを変えない。
- 問題完了・Stage完了・発見は短いジングルを重ね、BGMは必要量だけduckする。
- 「BoWのような切替」は特定楽曲の模倣ではなく、疎な基礎、意味イベント、土地ステム、余白、遷移予約という機能へ分解する。
- ミュート時にも土地変化、予兆、試練結果が視覚だけで分かるようにする。
