# 一本道物語再構成案 — 天空到達は最終章だけ

状態: 全36話・世界route再設計の判断正本  
決定日: 2026-08-10

## 1. 決定

本格的な雲上世界への到達は最終章（Stage 31〜36）だけにする。

旧「6学年 × 6土地」では、各学年の最後に雲上で事件を解決していた。この構造を36 Stageの一本道へそのまま移すと、天空到達、大団円、地上への帰還を6回反復し、最終目的地の価値と旅の上昇感が失われる。章間の接続文だけでは解決しないため、旧話の順番と場所を固定せず、人物・報酬・事件の役割を再配置する。

## 2. 新しい全体起伏

| 範囲 | 物語上の段階 | 主な空間 | 天空との距離 |
|---|---|---|---|
| Stage 1〜6 | 島の入口を知り、ひかりの種と身近な水路を直す | 南東草原、低地林、小川、山麓、砂浜、海辺の集落 | 古代樹は遠景と流木状の小根だけで予告 |
| Stage 7〜12 | 風の流れと島の地形を理解する | 山地、尾根、海岸、風車集落、樹冠下 | 雲上施設の影や風音を遠景で予告 |
| Stage 13〜18 | 星と夜の航路を取り戻す | 高地観測所、夜の海岸、玄武岩の記録洞 | 地上の観測施設と古い石記録から空を読む |
| Stage 19〜24 | 海の色と珊瑚の鐘を修復し、地下の根泉を見つける | 入り江、外礁、地下水路、古代樹外縁 | 古代樹の存在と島の水循環が初めて結び付く |
| Stage 25〜30 | 古代樹へ到達し、島の記録と王冠の異変を知る | 根元集落、古代樹内部、記録所、上昇路前庭 | Stage 30終端で初めて上昇路を開く |
| Stage 31〜36 | 仲間と成果を結び、天空の王冠へ向かう | 上昇根、雲霧集水庭、天空遺跡、王冠室 | 初到達。全編のクライマックス |

## 3. Stage 1〜6の修正

- Stage 1〜3は草原、低地林、小川、山麓を進む現在の入口地理を維持する。
- Stage 4は河口湿地からポケット浜を歩く。古代樹へ通じる海食洞や根門にはまだ入らない。
- Stage 5は岬裏の浜から海岸段丘と湧水路をたどり、南岸の小さな花壇集落へ向かう。漂着した古い小根や水路の刻印で、島の奥に大樹があることだけを予告する。
- Stage 6は海辺の共同花壇と小川へ三つの種を戻し、第1事件を解決する。遠景の島中央に巨大な樹冠が一度だけ見え、次の長い旅の目的候補になる。

Stage 4の旧終端 `海食洞の根門`、Stage 5の古代樹内部、Stage 6の雲上庭園は序盤から外す。絵コンテと3D routeは、`ポケット浜 → 海岸段丘・湧水路 → 南岸花壇集落`として再制作する。古代樹本体への到達はStage 25前後を目安に、全36話監査で確定する。

## 4. 再利用するもの

- 36話の友達、宝物、学習難度帯は原則として維持する。
- 「ひかりの種」「風」「星」「珊瑚の鐘」「記録」「王冠」という六つの事件は、一本の因果へ結び直す。
- 既存の雲上用ランドマークは削除せず、Stage 31〜36へ集約・再配置する。
- 既存Stage 1〜3のroute、絵コンテ、地学設計は大きく変更しない。Stage 4の砂浜までは維持し、後半の根門だけを海岸段丘側へ付け替える。

## 5. 作り直すもの

1. `storyConfig.ts`のStage 5〜30にある雲上到達・雲上解決の文言。
2. 全36 routeのうち、旧 `root→sky` と `sky→meadow` を反復する区間。
3. Stage 5以降の絵コンテ、3D制作brief、BGM意味区間。
4. 章ごとの大団円を、小さな解決と次の原因発見へ変更する物語テンポ。
5. Stage 31〜36へ天空の高度差、未知感、仲間の再登場を集中させる最終章設計。

## 6. 制作ゲート

- Stage 5以降の品質3D制作は、新routeと物語表の承認まで進めない。
- Stage 4までの制作と、島の共通地形・海・LOD基盤は継続してよい。
- キャラクター制作は世界routeと独立して継続してよい。
- 次に全36話を「目的・発見・解決・次への因果」で一行ずつ監査し、反復する展開を統合した新しいStage表を作る。
