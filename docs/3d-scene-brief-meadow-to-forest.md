## 1. この文書の役割

この文書は、草原から森へ連続前進する3Dシーンを制作・実装する際の直接の作業指示書である。制作担当は最初に本書を読み、不明点がある場合だけ参照資料を開く。

正本の優先順位:

1. 本書: この区間で承認済みの制作仕様
2. `docs/story-bible.md`: 世界観、地理、物語上の正史
3. `docs/game-design.md`: タイピング体験、UI、アクセシビリティ

本書と参照資料が矛盾する場合、物語の正史はストーリーバイブル、当該3D区間の画面仕様は本書を優先する。

## 2. 承認済みの目標

### 一文で表す体験

入力を続けると、明るい草原の細道から若木の間へ進み、成木を実際に通り抜け、柔らかな光の森へ包まれていく。

### 採用するアート方向

`簡略化した日本画調 × 透明水彩 × 控えめなファンタジー`

- 基礎造形: 日本画を思わせる大きな色面、余白、非対称な配置、簡略化した植物。
- 画材感: 透明水彩のにじみ、紙の微細な粒、岩絵具風の落ち着いた色。
- ファンタジー: 少数の光粒、青緑の水面光、古代樹へつながる薄い渦巻き模様。
- 森の密度: 個別の葉の描き込みではなく、幹、樹冠、低木の大きな面の重なりで表す。
- 輪郭: 強い黒線を使わず、色面と2〜3段階の柔らかな陰影で読む。

## 3. 制作範囲

### 今回作るもの

- タイピング進捗へ接続できる、0〜1の旅座標によるカメラ制御

## 4. 10秒の絵コンテ

| 時間 | 場所 | 必須の画面変化 |
|---:|---|---|
| 0.0秒 | 花の草原 | 細い踏み跡、広い空、少数の花。森は遠景に実在する。 |
| 2.0秒 | 林縁手前 | 若木と低木が道際へ入り、花が減り始める。 |
| 4.0秒 | 最初の成木前 | 草に落ち葉・苔が混ざり、幹が左右の近景へ来る。 |
| 5.5秒 | 森の入口 | 成木の間を物理的に通過し、樹冠が頭上を覆う。背景交換はしない。 |
| 7.5秒 | 森内部 | 高木、若木、低木、シダ、苔が層になり、幹が奥まで重なる。 |
| 10.0秒 | 小川手前 | 細い木橋、水面、橋の先の明るい抜け、遠い山の気配。 |

10秒は品質確認用の短縮再生であり、本番のステージ時間を固定しない。実装では旅座標0〜1へ割り当て、入力速度に応じて進行時間が変化する。

## 5. ルートとカメラ

### ルート

- 一本道だが完全な直線にはせず、左右へ緩く蛇行する。
- 草原側の踏み跡は幅約2.2〜2.5m。
- 林縁で幅約1.8〜2.2m。
- 森内部は幅約1.5〜1.8mの獣道・軽い登山道。
- 長方形の道メッシュを置かず、地形上の踏圧、土色、草の薄れで道を表す。
- 地面、植生、光、霧、音を異なる距離で変化させ、境界線を作らない。

### カメラ

- 一人称、地上約1.5mを基準。
- 35mm換算約28〜35mm相当の自然な広角。
- 道の曲線に沿い、機械的な中央直進にしない。
- 上下動と左右揺れは小さくし、タイピング中の酔いを防ぐ。
- 冒頭は進行を感じやすく、成木通過時は景色を読める速度へ少し落とす。
- 文が変わっても旅座標とカメラ位置を戻さない。

## 6. 環境と植生

### 森の型

温暖で湿り気のある落葉広葉樹林。コナラ、カエデ、シデ類を思わせる樹形を、児童書向けに簡略化する。

### 植生の層

1. 高木: 頭上で部分的につながる大きな樹冠。
2. 亜高木・若木: 高木の間を埋める細い幹。
3. 低木: 道際まで迫る大きな色面。
4. 草本: 扇形に簡略化したシダ、少数の草と森の花。
5. 林床: 大きな苔の面、落ち葉、丸い岩、小枝、倒木。

### 樹木モデル

- 成木3樹形: 横広がり、直立高木、傾いた林縁木。
- 若木2樹形。
- 幹は根元が太く、上へ先細りする。
- 樹高の半分前後から主枝を分ける。
- 葉は枝先ごとに3〜6個の大きな樹冠塊へまとめる。
- 左右対称、同じ高さ、等間隔の並木を避ける。
- 空の見える割合は森内部で約30〜45%を目安にする。

## 7. モデル・マテリアル一覧

### モデル

| ID | 内容 | バリエーション |
|---|---|---:|
| tree-canopy | 成木 | 3 |
| tree-young | 若木 | 2 |
| shrub | 低木 | 3 |
| fern | 扇形のシダ | 2〜3 |
| grass-clump | 草束 | 2 |
| forest-flower | 小さな森の花 | 2 |
| moss-rock | 苔むした岩 | 3 |
| fallen-log | 倒木 | 1 |
| trail-sign | 道しるべ | 1 |
| creek-bridge | 細い木橋 | 1セット |

### マテリアル

- meadow-ground: 淡い黄緑と生成りの水彩面。
- forest-floor: 翡翠、苔、落ち葉を大きな面で混ぜる。
- foot-trail: 暖かい土色。輪郭を不規則に欠かす。
- bark-light / bark-dark: 岩絵具風の色むら。細かな写真樹皮にはしない。
- leaf-light / leaf-mid / leaf-shadow: 葉群単位の3色。
- moss: 面として読める黄緑。細粒ノイズを増やさない。
- water: 青緑の透明感と少数の明るい筆致。
- bridge-wood: 暖かい木色。過度な木目を避ける。

## 8. レンダリング要件

- WebGLベースの3Dレンダラーを使用。
- 色面を保つ2〜3段階のトゥーン陰影。
- 紙の粒子は画面全体へ薄く一度だけ適用し、各素材で重複させない。
- 水彩のにじみは輪郭付近と色境界へ限定する。
- 強いアウトライン、フォトリアルPBR、鏡面の強い材質を避ける。
- 木漏れ日の影は細かな葉影を全面へ投影せず、大きな柔らかい光斑に整理する。
- 距離霧で遠景の彩度とコントラストを落とす。
- 風揺れは葉群・低木・草を異なる振幅で動かす。
- 光粒と発光は少数に制限し、常時派手にしない。

## 9. タイピング進捗との接続

最低限、シーンは次の入力を受け取れる構造にする。

```ts
type JourneySceneInput = {
  journeyProgress: number // 0〜1、文をまたいで単調増加
  isTyping: boolean
  typingPace: number      // 歩行揺れ、風、粒子の強さだけに使用
  reducedMotion: boolean
}
```

- カメラ位置は `journeyProgress` だけから決定できるようにする。
- `isTyping` は足取りや環境反応へ使い、停止時に座標を戻さない。
- `typingPace` でカメラ移動距離を直接飛ばさず、演出の強さを調整する。
- `reducedMotion` では歩行揺れ、強い視差、粒子を減らす。
- 一文の進捗 `sentenceProgress` を旅座標へ使用しない。

## 10. 完成条件

- 同じ空間を歩いて草原から森へ入ったと認識できる。
- 5.5秒付近に背景交換、暗転、クロスフェードがない。
- 道が公園の道路ではなく、細い踏み跡に見える。
- 森内部で高木、若木、低木、草本、林床の5層が読める。
- 森の密度は十分だが、進行方向と小橋を見失わない。
- 基準画像の日本画・水彩調が、単なる単色ローポリではなく材質と光に反映されている。
- UIを重ねる中央上部・下部に、常時読解を妨げる高周波な模様がない。
- 進捗スライダーを往復しても地形や植生が急に切り替わらない。
- 文を模した区切りを越えても位置が戻らない。

## 11. 禁止事項

- 広い道路、舗装路、広場状の中央空間。
- 完成背景画像のクロスフェード。
- ポータル、霧の壁、暗転による通常移動。
- 球状の葉を一つ載せただけの木。
- 等間隔の並木、左右対称の森。
- 個別の葉や花を大量に描く高周波な背景。
- 写真樹皮、写実的PBR、強い黒輪郭、ネオン発光。
- キャラクター、動物、文章、ロゴ、UIの環境素材への焼き込み。
- 最適化を理由に、承認済みの森の密度を先に下げること。

今回の反復で確定したこと:

1. ルート沿いだけへ樹木を増やしても森には見えない。地形と樹林をカメラ視錐台より広く作る。
2. 林縁は木の本数だけでなく、横方向へ占める範囲で判定する。
3. 森内部と小川の周囲にも外周樹林を続け、区間終端で環境を打ち切らない。
4. 橋は森を抜けた後ではなく、森内部の小川に架かる。
5. 次の土地は星見の山道なので、橋先の狭い抜けから遠山を見せ、海は見せない。
6. `typingPace` は足取り演出だけへ使い、旅座標と前進距離へ影響させない。
7. ストーリースクリプト接続前は、背景と環境小物を作り、台詞、動物、報酬、伏線記号を先回りして入れない。

次の作業:

3. 樹木、低木、シダ、岩、水面へベース材質の差を追加する。
4. 確認再生とゲーム歩行再生の両方で6地点を再検証する。
