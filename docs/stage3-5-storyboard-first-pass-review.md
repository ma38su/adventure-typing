## 共通制作条件

- 画風だけをStage 1正本から継承し、土地の内容は各Stage briefとroute-v2へ差し替えた。
- 六コマはroute-v2の六anchor順で、cameraは進行接線の後方、子どもの目線相当、地形追従とした。
- aerial shot、camera反転、背景交換、portal、teleportを禁止した。
- 海・山稜・谷・島中央の見える方向は球面routeの進行方位と遮蔽から決めた。
- 生成は組み込み画像生成を使用。画像を3D assetやtextureとして直接使用しない。

- 合格: 門、支尾根、低い星見台、谷川、限定的な海の初見、河口石橋の順が読める。

  低緯度雲霧林の広葉樹・風衝低木へ修正が必要。
- 判定: **構図・地理は条件付き合格、植生と道は修正要**。

## Stage 5「古代樹林から雲上へ」

対象: `artwork/preproduction/stage-5-ancient-root-to-cloud-storyboard-v1.png`

- route: 南西沿岸の根門から北東/島中央側へ、根際湿地→宙水泉→古土壌段→上昇根螺旋→雲霧集水庭。
- altitude: `0.12km → 1.76km`。物理的な根の坂と螺旋で高度を稼ぎ、垂直移動やwarpを使わない。
- camera: 根道の接線後方から徐々に上向き。panel 5で南西の海岸と島稜を下方に見せ、
  移動方位と高度を確認できる。panel 6も同じ根が石床へ接続する。
- 合格: 海の湿気が残る根門、巨根道、泉、開く根道、螺旋上昇、雲上庭園の順が明瞭。
- 未達: panel 1〜4の暗部が強く、ゲームUI下で道を失わない露出QAが必要。panel 3の三色光は
  item本体でなく控えめな予兆として実装する。panel 6の石床は広場化を避ける。
- 判定: **方向性合格、露出・予兆・広場密度は3D前に調整**。
