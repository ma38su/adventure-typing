# Stage 2 境界比較仕様

最終更新: 2026-08-10  
状態: v2 storyboard生成前の比較契約

## 提出画像

一枚の比較sheetに、同じ16:9 crop・camera高・画角で次の4枠を置く。文字ラベルは比較sheetの余白だけに置き、景観画像へ焼き込まない。

1. `A`: Stage 1正本第6コマ（橋への接近）
2. `B`: Stage 2 v2第1コマ（同じ橋を渡り始める）
3. `C`: Stage 2 v2第6コマ（星見門への接近）
4. `D`: Stage 3第1コマ仕様のproxy（門を抜けた直後、振り返らず同じ道を進む）

加えて、Three.js照合時は`worldProgress=.9999 / 1.0001`と`1.9999 / 2.0001`の二組を同形式で撮る。

## A→B: `evt-forest-creek-bridge`

| 固定対象 | 合格 |
|---|---|
| 構造 | 同じ床板数・幅・欄干高さ・木材色。別の橋に見えない |
| 地形 | 川幅、流向、両岸高、主要苔岩とシダの位置関係が一致 |
| route | Aの進行線がBへ折れずにつながり、橋の先でだけ右へ曲がる |
| 植生 | 対岸と左右外周に森の面が続く。橋で森が終了しない |
| 光 | 青緑の霧、露出、影方向が連続。時間帯が飛ばない |
| 不合格 | 橋の再設計、対岸が空地、背景交換、camera反転、川の流向反転 |

## C→D: `bnd-forest-mountain-a`

| 固定対象 | 合格 |
|---|---|
| 構造 | 同じ門石の輪郭、低いlintel、左右非対称、非発光 |
| 地形 | 同じ層状岩、鞍部の勾配、風衝草と残存樹木の混在 |
| route | Cで門越しに見えた左曲がりがDの手前道になり、接線差1°以下 |
| 遠景 | 灰青稜線の方向と高さが連続。海や別山系を追加しない |
| 光 | 夕金と灰青の比率を維持。門通過で露出を変えない |
| 不合格 | portal、暗転、巨大門、門の先が空白、山sceneへの背景交換 |

## 画像承認条件

- A/BとC/Dそれぞれで固定対象5項目すべて合格。
- 対応物を説明用矢印なしで同定できる。
- 1024×768 cropで上12% HUD、下24% typing safe zoneを半透明帯として重ねても、橋/門、次の曲がり、最明部が隠れない。
- 景観承認時はキャラクターを含めない。キャラクターは次のoverlay gateで同じcropへ合成する。
- 差戻しは`G`を主分類とし、どの固定対象が変わったかを一項目だけ指定する。v1または承認前画像を正本名で上書きしない。

## Three.js照合条件

- 境界位置差0.05m相当以下、接線差1°以下。
- 同じcanvas / scene / camera / BGM transportを維持し、reload/reset 0。
- 橋・門・道・地表を重複生成せず、隙間もない。
- console error 0。境界往復または再撮影でgeometry / material / textureが増殖しない。
