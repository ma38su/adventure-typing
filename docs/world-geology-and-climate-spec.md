## 1. 結論

ことば島は、**低緯度の海洋上にある、活動を終えて侵食が進んだ玄武岩質火山島**として設計する。北〜北西の星見山脈は旧火山体のカルデラ縁と岩脈帯、中央〜南東は緩い溶岩原、南西は侵食谷が沈水した湾である。東〜北東からの卓越風を受け、北東斜面は多雨、南西斜面は雨陰になる。これにより、草原、深い森、山道、入り江、根の洞、雲上遺跡が一つの因果でつながる。

物語の出来事順と「連続移動して同じ六地域を再訪する」構成は維持できる。変更すべきなのは方位そのものより、次の四点である。

1. 南西湾の川の河口と珊瑚礁・白砂浜を同じ場所に重ねず、濁る河口湿地と澄んだ外湾礁を分ける。
2. 低地の「落葉広葉樹林」を、季節性のある亜熱帯常緑・半常緑林へ改め、標高の高い森を雲霧林にする。
3. 雲上遺跡は地学上の山頂ではなく、古代樹が支えるファンタジー構造物と明記する。地表最高点1.25kmに対し1.65〜2.05kmの遺跡を通常地形として扱わない。
4. 一章約30〜38km、全六章約190〜220kmのrouteは、17×16kmの島を六回別レーンで巡る旅として成立する。球面route距離を地図と3D worldの唯一の正本にし、見える速度を上げず、距離と景観beatに応じて短文問題・course数を増やす。

## 2. 現行仕様の監査結果

### 2.1 維持してよい骨格

- 島中心12.025°N、142.000°E、東西約17km・南北約16kmという局所座標。
- 北〜北西に山地、北東〜中央に森、南東に緩丘、南西に入り江、中央に古代樹という大配置。
- 山地から森を通って海へ流れる水系。
- 六章が同じ地域の100〜350m離れた別回廊を通り、前章の結果を再訪時に確認する構成。
- Stage境界でロード・暗転・ワープを行わず、共有chunkで連続する原則。

### 2.2 修正が必要な不自然点

| 現行記述 | 問題 | 修正方針 |
|---|---|---|
| 12°N低地の「面積ある落葉広葉樹林」 | 年間を通じて温暖な低緯度島の基調植生として不自然 | 北東低地を亜熱帯常緑・半常緑林、尾根を風衝低木林、700m以上を雲霧林とする |
| 山川の河口、白砂、浅い珊瑚礁が南西湾の同一点 | 洪水時の細粒土砂と淡水が珊瑚の透明な浅海環境を損なう | 湾北部を河口・湿地・暗色砂、湾南部〜外縁を白砂ポケットビーチ・裾礁に分離する |
| 山脈があるが成因・分水嶺がない | 川、雨陰、土壌、植生配置の理由が弱い | 北西山地を侵食されたカルデラ縁・岩脈帯とし、弧状分水嶺を定義する |
| 古代樹の根が「全地域地下へ」均等に伸びる | 地下水・基盤地質との区別が曖昧 | 根は旧溶岩トンネル・破砕帯を選択的に通る。水理接続そのものではなく、水の位置を読む生物構造とする |
| 古代樹から1.7km以上へほぼ鉛直上昇 | 地表の連続歩行として急すぎる | root–skyだけは人工・生物建造物の長い螺旋回廊。地学routeではなく文化景観として明示する |
| 1.65〜2.05kmに「雪うさぎ」 | 12°Nの2km以下で恒常的な雪を期待できない | 「雲うさぎ」または白い固有ウサギへ変更。雪は置かず、雲滴・白色地衣・冷涼な風で高所感を出す |
| ニホンジカ、ニホンリス等の名称 | 架空の熱帯海洋島の固有相として地理的に不整合 | 「島シカ」「樹上リス」等の固有種名にし、人為移入種か固有種かを決める |
| オオカミ、ライオン、山ヤギ | 17km島の野生個体群として維持困難 | 実在生態系の常在動物にせず、古代の守り手の精霊・石像投影とする。通常発見枠は鳥・昆虫・小型哺乳類へ置換する |
| Stage 1〜6で島を一周し、以後ほぼ同じ地域順 | 物語上は成立するが、一本道が六重の周回路に見える | 「一周」ではなく一つの主要流域と外輪山を巡る巡礼環と定義。方位表現より水系・風・ランドマークで進行方向を伝える |

## 3. 地質史

### 3.1 形成モデル

1. 約150〜80万年前、海底火山が成長し、緩斜面の玄武岩質楯状火山島を形成した。
2. 活動後期、北西寄りの山頂部が小規模に陥没し、弧状カルデラ縁と北東・南西方向の岩脈群を残した。
3. 火山活動停止後、東〜北東から運ばれる湿気と河川侵食により、風上側に短く深い谷、風下側に長い谷と扇状地が発達した。
4. 海面変動と沈降により南西谷の下流が沈水し、半月形の入り江になった。湾北部には沖積層、湾南部には波食棚と珊瑚由来の砂が蓄積した。
5. 古い溶岩トンネルと岩脈沿いの破砕帯が、古代樹の根道、湧水、文化的な地下回廊として利用された。

古い火山島が侵食・沈降し、谷、海食崖、裾礁を発達させるモデルはUSGSの火山島解説と整合する。地下水は透水性の高い溶岩流中の淡水レンズに加え、岩脈や火山灰・古土壌で堰き止められた高所地下水を持つ。

## 4. 地形・流域・海岸

### 4.1 分水嶺

弧状分水嶺を `12.090N,141.970E → 12.082N,141.995E → 12.068N,142.018E` に置く。最高峰は `12.086N,141.982E, 1.25km`。現行Stage 2/8/14等の山側終点はこの南側斜面または鞍部にあり、越えるのは山頂ではなく標高630〜800mの峠とする。

北東風上側の2本は中央河川へ無理に合流させず、分水界から北東・東海岸へ直接下る短い急流とする。中央南側には南西湾へ下る独立流域を置く。透水性の高い玄武岩では地表水が少なくなるため、恒常水面は次の4本と小規模水体へ限定する。

- 東風上沢: 集水域約6.8km²、見かけの満水幅約12m。中央鞍部から東海岸へ下る。
- 北東雨森沢: 集水域約9.4km²、満水幅約15m。多雨の雲霧林から北東海岸へ下る。
- 南西谷川: 集水域約23.5km²、下流満水幅約26m。中央南側から南西沈水湾へ下る主流。
- 溶岩層境湧水沢: 集水域約2.2km²、幅約9m。溶岩流境界の宙水が短い沢として南西谷川へ入る。

全制御点について下流側標高が上流側を超えないことを自動検証する。レンダラーは`widthKm`を全幅として扱い、左右へ同じ値を足して2倍にしない。沢筋の谷は水路中心からの距離、集水域、下流度で浅く侵食し、物語上の地点を結ぶために尾根を横断させない。

### 4.2 河口と珊瑚入り江

現行の単一河口座標 `12.015N,141.945E` は、**湾北部の河口湿地**として維持する。Stage 3終端は白砂ではなく、丸石・暗色砂・葦のある河口縁へ変更する。

白砂と裾礁は河口から南へ2〜4km離れた `11.985〜12.005N,141.936〜141.960E` に置く。岬が北からの濁水を遮り、卓越風の風下側で波が比較的穏やかなため、珊瑚片と有孔虫砂が残る。Stage 4、10、16、22、28、34は湾岸を南下または北上して、河口・船着き・白砂・波食洞を別々に通る。

珊瑚は湾全面に均一配置せず、外湾の水通しがよい浅所に裾礁、内湾に海草藻場、河口前面に砂泥底を置く。海食洞は玄武岩の弱線と旧溶岩トンネル出口が波で拡大したものとする。

### 4.3 侵食と崩壊の表現

- 風上斜面: 深い谷、段瀑、崩積土、太い露出根。
- 風下斜面: 丸い尾根、涸れ沢、厚い風化土、点在する岩塔。
- 山道: 等高線に沿う獣道幅1.2〜1.8m。谷頭を直線横断しない。
- 海岸: 湾内は砂浜、岬は波食崖、岬裏はポケットビーチ。すべてを白砂にしない。
- 西の高波浪海岸: 海食崖の基部だけに低く緩い玄武岩波食棚を置き、潮だまり、岩礁、沖の海食柱を一組で表現する。
- 沖の小島: 北・北東の2島は旧火山体または抵抗性岩脈の侵食残丘、西岸の細い岩塔は海食柱として区別する。

## 5. 気候・風・植生帯

### 5.1 気候前提

- 緯度: 12°N。通年温暖な海洋性熱帯〜亜熱帯。
- 卓越風: 年間の基調は東北東風。物語上「風が止まる」は気候の消失でなく、古代の送風施設と局地循環の異変とする。
- 雨季: 5〜11月、乾季: 12〜4月。台風相当の強い嵐は稀だが存在する。
- 山地で地形性上昇が起こり、北東斜面は多雨。南西湾と南東草原の一部は雨陰で相対的に乾く。
- 雲底は天候で変わるが、山地の700〜1,100mを雲霧帯として頻繁に雲が触れる。雪氷帯は設けない。

### 5.2 標高・水分による植生

| 帯 | 条件 | 植生 | 主なStage表現 |
|---|---|---|---|
| 海岸帯 | 0〜50m、塩風 | 海浜草本、タコノキ類、低木、河口湿地、海草藻場 | 3〜4、9〜10ほか入り江区間 |
| 風下低地 | 50〜250m、季節乾燥 | 花草原、疎林、二次草地、耕作地 | 1、6〜7、各章の草原再訪 |
| 風上低地林 | 100〜600m、多雨 | 常緑・半常緑広葉樹、シダ、着生植物 | 1〜2、7〜8ほか森区間 |
| 山地雲霧林 | 600〜1,100m、霧・強風 | 低い常緑樹、木生シダ、苔、着生植物 | 森→山境界、星見支流源頭 |
| 風衝尾根 | 800〜1,250m、薄土 | 低木、束生草、地衣、露岩 | 3、9、15等の山稜 |

森の季節変化は一斉落葉ではなく、乾季の葉量低下、花期、若葉、落葉の局所差で表現する。水彩の柔らかさは保ちつつ、樹冠層・亜高木層・低木層・林床の四層を読める密度にする。

## 6. 地下水と古代樹

雨は北東斜面と雲霧林で涵養され、次の三系統へ分かれる。

1. 透水性の高い溶岩流を通って海水上の淡水レンズへ入り、海岸湧水・海底湧水として出る。
2. 岩脈に遮られて高所に貯まり、森と星見山の恒常湧水を支える。
3. 火山灰・古土壌上の宙水となり、古代樹の泉や季節湿地を支える。

古代樹は島全体の地下水を魔法で生成しない。根が岩脈・溶岩洞・湧水線をたどるため、島民には「根が水を運ぶ」ように見える、という関係にする。根の発光は地下水量の可視化、根門は溶岩洞の崩落窓を文化的に整備した入口である。これならStage 4→5の海食洞から根道への接続と、Stage 5→6の上昇構造を分けて説明できる。

## 7. 生物地理と動物発見の修正

17×16kmの孤立島では、大型捕食者や多数の大型草食獣の野生個体群は維持しにくい。通常の発見対象は、飛来・分散可能な鳥、昆虫、海生動物、小型固有哺乳類を中心にする。

| 現行候補 | 地学・生態改訂 |
|---|---|
| ノウサギ、キツネ、シカ | 古い入植時に持ち込まれた小個体群なら可。固有種扱いなら小型化と保全区域を設定する |
| シジュウカラ、ニホンリス | 現実地域名を外し、島小鳥・樹上リス。森の種子散布者として文化に結ぶ |
| 山ヤギ | 移入家畜が野生化すると植生を壊すため、村で飼育する崖ヤギか精霊像にする |
| ラッコ | 12°Nの珊瑚海には不適。カワウソ風の架空沿岸種、またはウミガメへ変更する |
| 雪うさぎ | 雲うさぎ／白い島ウサギへ改称。雪景観は作らない |
| フクロウ、ワシ | 島固有または渡り個体として可。猛禽は少数・広い行動圏を示す |
| イルカ、熱帯魚 | 外湾礁と航路に適する。河口濁水域では熱帯魚群を出さない |
| オオカミ、ライオン | 野生動物でなく古代の守り手の精霊。足跡など実在個体群を示す予兆は使わない |

章ごとの再発見は同じ個体または季節差にする。同種を別地域へ都合よく配置せず、巣・餌・水・退避方向をproduction briefに一行ずつ持たせる。

## 8. 地理から生まれる地域・文化

### 8.1 南東・花風地方

- 雨陰の緩い溶岩原と古い火山灰土。花草原の一部は自然草原でなく、島民が維持する採種地・放牧跡。
- 文化: 種の交換、風向旗、小風車、乾季の共同水路。建物は低く、風を通す深い庇。
- Stage 1の船着きは外洋直面でなく、南東岬裏の小湾に置く。

### 8.2 北東・木漏れ日地方

- 雨を受ける森と短い急流。木材を皆伐せず、倒木・樹洞・果実を採る文化。
- 文化: 樹上歩廊、どんぐり笛、雨水槽、音で位置を伝える森道。
- 森の集落は氾濫原を避け、低い尾根肩に置く。

### 8.3 北西・星見地方

- 旧カルデラ縁、強風、雲霧、露岩。観測に適した鞍部がある。
- 文化: 石積み風除け、星見台、風見羽根、岩脈の節理を使った碑文。農耕より牧畜・薬草採取。

### 8.4 南西・珊瑚湾地方

- 河口湿地、内湾藻場、外湾裾礁が連なる。
- 文化: 河口の淡水舟と外湾の帆船を使い分ける。珊瑚を採掘せず、漂着片と音響石で鐘を修復する。
- 住居・桟橋は高潮帯より上。礁の水路標識は潮位と星座の両方を読む。

### 8.5 中央・月影地方

- 溶岩洞、陥没窓、宙水泉、巨大樹の根系。
- 文化: 水量記録、根を傷つけない浮き床、湿気に強い樹皮紙と石棚。図書館がここにある理由を乾燥ではなく、温湿度が安定する洞内環境と管理技術に置く。

### 8.6 雲上・風環地方

- 自然地域ではなく、古代樹とカルデラ岩をアンカーにした人工高所遺跡。
- 文化: 地上六地方の水、風、航路、記録を観測する共同施設。王の宮殿でなく、共同管理所という最終章の意味に一致する。

## 9. 球体・島サイズ・移動距離監査

### 9.1 球体表現

惑星半径6371km相当は問題ない。17kmの島では地表曲率による中央の膨らみは、端から端17kmに対して約5.7m、地平線までの距離は視点高2mで約5kmである。地上カメラで「球体」を誇張すると島が小惑星に見えるため、通常3Dでは現実的な曲率のままとし、球体性はグローブ画面と遠望地点で示す。

緯度経度範囲 `11.955〜12.105N` は南北約16.7km、`141.925〜142.085E` は東西約17.4kmで、記述値と整合する。

### 9.2 現routeの概算と単一距離契約

座標アンカー間の水平距離は多くが約5〜8kmで、一章の地表・上昇routeは概ね30〜38kmになる。六章では約190〜220kmである。同じ島を六回、別レーンで巡る設定として地理的に可能であり、次を契約とする。

- 球面座標から算出する`routeDistanceKm`を地図routeと3D world routeで共有し、二重の距離正本を持たない。
- 空間短縮、途中skip、teleportは行わず、chunk streamingと原点rebasingでroute全体を連続保持する。
- `worldProgress`は物語進捗だが、同じ球面route上の位置へ単調写像する。文・コース・Stage境界で戻らない。
- 見える前進速度を不自然に上げない。`ceil(routeDistanceM / 150)`、六コマ・発見・境界beat各3問を基礎に18〜60問・可変courseを見積もる。60問を超える場合は速度でなくroute設計を再レビューする。
- Stage 5等の1.6km上昇は古代建造物内の螺旋上昇として、同じ距離正本上で通過する。

推奨データ:

```ts
type JourneyStageGeography = {
  routeDistanceKm: number
  elevationGainM: number
  watershedId: string
  climateZoneId: string
}
```

## 10. 方位とStage routeの改訂案

方位に物語上の意味はないため、ストーリーラインを変えずに局所routeを修正してよい。ただし大配置は変える必要がない。推奨は「南東→北東林→北西山→南西湾→中央古代樹→雲上→南東」の反時計回りを維持し、地理的意味を加えることである。

- Stage 1: 南東の岬裏船着き→雨陰草原→湿度が増す北東林縁。
- Stage 2: 森支流を上流へたどり、雲霧林を経てカルデラ鞍部へ。
- Stage 3: 鞍部から南西谷を下り、白砂でなく河口湿地へ。
- Stage 4: 河口から湾岸沿いに南へ進み、白砂・裾礁・海食洞を順に通る。
- Stage 5: 海食洞→古溶岩洞→古代樹→人工螺旋上昇路。
- Stage 6: 雲上施設→東側の人工下降路→南東草原。以後の章は隣接レーン。

Stage 12→13の現座標は、雲上遺跡内で終わるStage 12に対しStage 13開始が地上下降済みに見える。Stage 13前半に下降を含める現行説明を座標表へ明示し、Stage 12終点とStage 13開始を同一点 `(12.029,141.998,1.91)` にする。Stage 13の地上アンカー `(12.046,142.022,0.26)` は中間点へ移す。これで再ロードなし契約と座標表が一致する。

Stage 36は雲上で終わってよいが、ワールドマップの最終routeは王冠室で途切れず、「島全体へ約束が伝わる」非歩行の光環を別レイヤー表示する。プレイヤー移動線と物語効果線を混同しない。

## 12. 制作時の地学受入基準

- 川は尾根を越えず、必ず分水嶺から低所へ流れる。
- 滝、湧水、湿地には岩脈・不透水層・谷底などの理由がある。
- 河口濁水域と外湾珊瑚礁が同じ水面テクスチャ・同じ生物密度にならない。
- 標高と風上・風下に応じて樹高、葉量、林床、水分が連続変化する。
- 山頂に達した直後に海岸へ切り替わらず、谷頭→支流→本流→河口の順で下る。
- 古代樹の根は全地形を無視して直線に伸びず、溶岩洞・破砕帯・湧水線を選ぶ。
- 地上自然景観に恒常雪を置かない。
- 動物発見は餌、水、巣・休息場所、退避方向の四点を説明できる。
- 文化施設の材料と場所が、地域の岩石、木、水、風、海況に対応する。
- 地図と3Dが同じ`routeDistanceKm`を参照し、空間短縮・途中skip・teleportを行わない。
- 3D地上画面で球体曲率を誇張せず、グローブと遠望で球体世界を伝える。

## 13. 参照した一次・公的資料

- [USGS: Islands](https://www.usgs.gov/programs/coastal-and-marine-hazards-and-resources-program/science/islands) — 火山島の形成環境、侵食、堆積物、淡水制約。
- [USGS: Evolution of Hawaiian Volcanoes](https://www.usgs.gov/observatories/hvo/evolution-hawaiian-volcanoes) — 火山活動後の風化、谷・海食崖、沈降、珊瑚礁への長期変化。
- [USGS: Hydrogeology of the Hawaiian islands](https://www.usgs.gov/publications/hydrogeology-hawaiian-islands) — 溶岩帯水層、淡水レンズ、岩脈で堰き止められた地下水、高所湧水。
- [USGS: Volcanic aquifers of Hawai‘i—Hydrogeology, water budgets, and conceptual models](https://www.usgs.gov/publications/volcanic-aquifers-hawaii-hydrogeology-water-budgets-and-conceptual-models) — 透水性溶岩、不透水岩脈・火山灰・古土壌、沿岸caprockの水理モデル。
- [USGS: Geology and ground-water resources of Kauai](https://www.usgs.gov/publications/geology-and-ground-water-resources-island-kauai-hawaii) — 侵食谷、海食崖、沖積化、波食棚、珊瑚礁を持つ古い火山島の実例。
- [NOAA: What is a watershed?](https://oceanservice.noaa.gov/facts/watershed.html) — 高地から流出点へ水を集める集水域と、地下浸透・河川流出の関係。
- [USGS: Wave-Cut Platform](https://apps.usgs.gov/thesaurus/term-simple.php?code=GC-139&thcode=62) — 海食崖の基部から海へ延びる緩斜面という波食棚の定義。
- [USGS: Coastal knickpoints and fluvial/wave erosion](https://www.usgs.gov/publications/coastal-knickpoints-and-competition-between-fluvial-and-wave-driven-erosion-rocky) — 河川の下刻と海食崖後退が沿岸谷・滝を決める条件。

これらは現実のハワイを複製するためでなく、小さな低緯度火山島で地形・水・植生がどう因果づくかの参照である。ことば島固有の古代樹、発光根、雲上遺跡、言葉の力はファンタジー要素として残すが、自然地理と混同しない。

## 14. 正本への変更前後対応表

| 対象 | 変更前 | 統合後 |
|---|---|---|
| 島の成因 | 弧状山脈のみ | 侵食された低緯度玄武岩火山島、旧カルデラ縁・岩脈帯 |
| 風・雨 | 方位との因果なし | 東北東卓越風、北東多雨、南西雨陰、若雨・花風の季節相 |
| 水系 | 一本の山川 | 北東・東へ直接下る風上2流域、南西主流域、溶岩層境湧水沢、淡水レンズ・高所地下水・宙水 |
| 南西湾 | 河口に白砂・珊瑚 | 北の河口湿地→砂泥・海草藻場→岬裏白砂→外湾裾礁→海食洞 |
| 森 | 低緯度の落葉広葉樹林 | 低地の亜熱帯常緑・半常緑林、山地雲霧林、風衝尾根 |
| 雲上 | 自然地形に近い扱い、雪うさぎ | 人工・生物構造物、恒常雪なし、霧氷色の雲うさぎ |
| 古代樹 | 根が全地域へ均等に伸びる | 溶岩洞・破砕帯・湧水線を選び、水を記録・配分する |
| Stage 3→4 | 河口白砂から珊瑚浜 | 河口湿地から湾岸を進み、藻場・白砂・外礁を順に通る |
| Stage 12→13 | イベントID中心で空間境界が曖昧 | 同一`bnd-sky-star-route`、同一高所座標からStage 13内で実体下降 |
| 距離 | 地図用と3D体験用を分ける監査初案 | 球面`routeDistanceKm`を唯一正本にし、空間短縮・skip・teleport禁止 |
| 問題密度 | 5 course×3問の旧検証値 | 距離・六景観anchor・発見・境界から18〜60問、6〜9問/courseを可変算定 |
| 景観リズム | 六コマの構図差 | 各コマをmicro-landformへ固定し、前anchorから七軸中最低二軸を変更 |
