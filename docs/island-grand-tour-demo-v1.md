# ことば島 ぐるっと周遊デモ v1

## 目的

物語や学年構成を先に固定せず、ことば島の地形・気候・海岸帯から導いた特徴的な場所を、一つの3D地表と一つの閉じたrouteで巡って評価する。

## コース

`南東の花草原 → 東の木漏れ日林 → 北東の雨の森 → カルデラ見晴らし台 → 西の風見尾根 → 南西河口湿地 → 岬裏のポケット浜 → 湧水の谷 → 玄武岩柱の盆地 → 南岸花壇集落 → 花草原`

- 天空は含めない。
- 世界樹・古代樹を島の成立条件や中央ランドマークにしない。中央部は古い火口底、湧水谷、玄武岩柱、草地で成立させる。
- 海岸は河口湿地、白砂、浅海、外礁を同じ地形正本上で分ける。
- routeは背景交換、暗転、teleportを使わず閉じる。
- routeは地点間の直線ではなく、海岸段丘、小川の谷、斜面のつづら折り、低い鞍部、尾根の肩をつなぐ。全39制御点を陸上に置き、隣接制御点間の実標高勾配を22%未満にする。
- 全島模型の火山地形と高低差は保つ。周遊デモの表示倍率は3.6倍とし、高さを潰すのでなく、谷・鞍部・等高線沿いの折返しによって登れるrouteにする。

## 周遊体験の設計原則

- 高峰は遠くから方角を知らせるランドマークであり、routeを山頂へ直結しない。
- 開けた草原、密な森、見晴らしのよい肩、湿地、浜、涼しい谷、火口盆地を交互に置き、同じ景色を連続させない。
- 登りの前後に平坦な休息区間と眺望を置く。斜面は谷筋、鞍部、つづら折りで横切る。
- 一本の正解線を強制するためではなく、将来のgameplay-near LODで枝道・展望所・短い寄り道を作れる地理骨格とする。
- 南西の河口湿地から岬裏のポケット浜までは、内陸へ戻らず海岸線と並行する砂浜歩行区間にする。干潟、濡れ砂、乾いた白砂、岩岬の順に足元を変える。

## デモ操作

- 自動再生／一時停止
- 全島俯瞰／地表追従の切替
- 周遊位置slider
- 10地点への直接移動
- 地表追従中は、左右ドラッグで回り込み、上下ドラッグで視線を上下、ホイールで距離を変更
- 視点リセット

## 実装境界

地形と海は既存のcanonical island surfaceを使う。ルートとデモ用の簡略ランドマークは評価層であり、正式なgameplay propsではない。承認後は、各区間を同じ座標のregional-corridor / gameplay-near LODとして作り込み、別の島を作らない。22%は全島模型の制御点間を監査する上限であり、実際の歩行用LODではさらに細かな折返しと地形整形を入れ、短区間の体感勾配を緩める。

全島の自然要素は [オープンワールド環境データ設計](island-open-world-data-model.md) に従う。木・低木・草・花・葦・玄武岩は決定論的セルから描画し、三支流・ことば川・南西の河口湾も同じ地理座標を使う。
