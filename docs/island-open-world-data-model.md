# ことば島 オープンワールド環境データ設計

## 目的

全島模型と実際に歩くフィールドを別々の島として作らず、同じ地理データを距離と用途に応じたLODで描画する。現在の周遊デモは、この構造を検証する全島ビュー兼移動カメラである。

## 共通データ層

| 層 | 正本 | 用途 |
|---|---|---|
| 地形 | `islandTerrainSurface.ts` | 海岸線、標高、気候、流域、海岸帯 |
| 周遊route | `islandGrandTour.ts` | 景観確認用の閉路と見どころ |
| 水系 | `islandHydrology.ts` | 三支流、ことば川、南西の河口湾 |
| 自然環境 | `islandEnvironment.ts` | 木、低木、草、花、葦、玄武岩の決定論的配置 |

## 地表材質

気候区分を三色の帯として直接塗らない。湿度、標高、海岸からの距離を連続値として混ぜ、乾いた溶岩土、湿潤土、草地、露岩へ徐々に変化させる。海も深海・外礁・浅海の分類境界を色帯にせず、水深から連続的に色を求める。

全島LODでは固定シードの低周波色むらと細粒を一枚の手続きtextureとして重ねる。regional/gameplay LODでは同じworld座標を入力にし、腐植、苔、落葉、砂礫、濡れ面などのmaterial layerを追加する。カメラ移動やセル再ロードで模様の位置を変えない。

## セルとLOD

自然環境は安定したIDを持つ約650m四方のセルに分割する。同じセルを再ロードしても種類・位置・回転・尺度は変わらない。

- `globe`: 樹林や湿地を色面と少数の代表形状で表示する。
- `regional-corridor`: 現在地周辺と進行方向のセルを読み込み、群落の密度と主要樹形を表示する。
- `gameplay-near`: 道の周囲を個体モデル、地表植生、倒木、当たり判定、発見演出へ置換する。

LODは同じinstance IDを段階的に詳しくする。近景ロード時に別座標へ木を生やしたり、遠景の山・川・湾を交換したりしない。

## 現在の実装範囲

- 全島のセルと環境instanceを決定論的に生成する。
- 気候・標高・海岸帯から7種類の自然要素を選ぶ。
- 北東の湿潤側は高密度林、南西の雨陰は草・花・岩、河口は葦を優先する。
- ルート中心から一定幅を空け、歩行路を樹木で塞がない。
- 植生を広い帯状に削除せず、樹木・岩・倒木を障害物としてmacro routeを局所的に横へ逃がし、平滑化した中心線を使う。
- Three.jsでは同種をInstancedMeshでまとめる。
- 南西の沈水湾へ流れ込む三支流と本流を全島座標上に表示する。
- 全島試作では2048px shadow mapによるリアルタイム影を使う。静的ベイクは景観と太陽方向が固まるまで行わない。

## 次の制作ゲート

1. 全島俯瞰で森・雨陰・湿地・川・湾の大配置を承認する。
2. 草原→東林の1セルをgameplay-near品質へ作り、遠景instanceとの位置一致を確認する。
3. 移動に応じたcurrent/forward cellのload・behind cellのunloadを実装する。
4. 衝突、枝道、採集可能物、動物の遮蔽をnearセルだけへ追加する。
5. Stage 1→2境界でterrain、水系、植生セル、BGMが再ロードなしに継続することを確認する。
