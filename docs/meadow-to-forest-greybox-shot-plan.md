# 草原から森へ・3Dグレーボックス画面設計表

最終更新: 2026-08-09
状態: 設計承認済み・実装可能
対象: `花の草原 → 林縁 → 成木通過 → 森内部 → 小川手前`
画面基準: `artwork/preproduction/meadow-to-forest-storyboard-nihonga-simplified-v1.png`

## 1. この文書の目的

技術要件だけを満たす単色の通路や柱列を作ることを防ぎ、6コマの構図を実装前に固定する。数値は最終モデル数ではなく、カメラから見た密度と画面占有を拘束する範囲である。

参照優先順位は次の通り。

1. 本区間の画面目標: `docs/3d-scene-brief-meadow-to-forest.md`
2. 承認済み画面基準画像
3. 本書の6コマ構図
4. 世界観・物語: `docs/story-bible.md`
5. タイピング中の視認性: `docs/game-design.md`
6. 技術契約: `docs/watercolor-renderer-implementation.md`

技術要件が画面目標を損ねる場合、同一空間・共通中心線・地形追従・進捗保持という契約は維持しつつ、植生数、LOD、描画コスト、汎用化を後回しにする。技術契約を理由に、草原の開放感、森の有機的な密度、橋への見通しを削らない。

## 2. 全区間に共通する画面規則

- 一本道だが、中心線は緩く蛇行し、画面中央へ常に一直線の消失点を作らない。
- 高木を左右一対、同じ距離、同じ高さへ置かない。同じ側でも連続間隔を変え、空白区間を意図的に設ける。
- 道は均一な明色面にしない。連続する土色の踏圧を主とし、苔・落ち葉・短草を不規則な小面積で戻す。横断帯、中央一列、等間隔の斑点は禁止。
- 近景は太い幹、根、岩、シダなど少数の大形。中景は若木、低木、林床の重なり。遠景は低彩度の森面・山・空気遠近で構成する。
- 樹冠は一本の水平板にせず、一樹につき3〜5個の高さ・角度・大きさが異なる塊を交差させる。画面上端を一枚で横断させない。
- 中央上部と下部はタイピングUI予定域として高周波の細部を抑えるが、空白のトンネルにはしない。
- 10秒デモの位置は `s=0,.2,.4,.55,.75,1` に一致させる。コマ間は物体の交換ではなく、同じ物体への接近と通過で変化させる。

## 3. 6コマ設計

### s = 0.00 — 花の草原

| 項目 | 設計 |
|---|---|
| 感情 | 「旅が始まる」開放感、安心、遠くの森への小さな期待。 |
| 必須要素 | 画面の50〜65%を占める広い空、草の丘、細い踏み跡、少数の花、地平近くの林縁、淡い山。 |
| 近景 | 草と花のまとまりを左右非対称に2〜4群。高木・太い幹は置かない。踏み跡の入口を草が少し欠く。 |
| 中景 | なだらかな丘と蛇行する踏み跡。低い灌木は0〜2群。森の高木はまだ近景化しない。 |
| 遠景 | 林縁を低い連続色面として画面幅25〜40%。その背後に低彩度の山。森は目的地として実在するが、幹の一本一本は主張させない。 |
| 木・距離・空 | カメラから約25m以内に高木0本。25〜45mに林縁の樹冠群。空の抜け55〜70%。 |
| 道 | 幅2.4m。土色は淡いが、中心を一色で塗らず草切れを3〜5%、小石・暗色面を少量。縁を草花で不規則に欠く。 |
| 光・霧・色 | 明るい青緑の空、黄緑と生成り。霧は遠景だけ。コントラストは全区間で最も低く明るい。 |
| 前後差 | 開始点。次コマへ向けて花と空が減り、若木・低木が増える。 |
| スケッチ対応 | 左上コマの広い空、遠い山、花の左右群、中央へ緩く続く明るい踏み跡。 |

| 不合格 | 橋が一枚の台形、水が一枚の巨大平面、対岸の道がない、樹冠板が橋や空を塞ぐ。 |

## 4. グレーボックスで作り込むもの／作り込まないもの

### 作り込む

- 6コマごとのカメラ構図と前後コマの連続性
- 一本のルート、道幅、地形高、橋中心の一致
- 木の前後・左右距離、樹高、画面占有、空の抜け
- 5層の植生を識別できる仮形状と密度
- 道の低周波な色むら、苔・土・落ち葉の大きな面
- 小川、橋板、両岸、対岸の道、明るい抜け
- 近景・中景・遠景の色と霧の差
- デバッグ時の中心線・幅境界・カメラ・先読み・橋中心の可視性

### 作り込まない

- 写実的な樹皮、個別の葉、細密な花
- 最終水彩シェーダー、紙粒子、輪郭にじみ
- 完成版の風・水面・光粒アニメーション
- キャラクター、動物、報酬、物語イベント
- 全地域対応、汎用エンジン化、iPad最適化
- ゲーム本体への統合

## 5. 旧試作から引き継ぐ具体要素

- 固定シードの決定的な配置とテクスチャ生成の考え方
- 草、苔、土、落ち葉を単色でなく大きな色面として混ぜる林床
- 近景を濃く、遠景を低彩度にする距離霧と空気遠近
- 幹、若木、低木、草、岩、根、倒木を重ねる密度差
- 暖かな樹皮、青緑の霧、黄緑の木漏れ日という落ち着いた色調
- 個別葉ではなく、複数の樹冠塊で一樹を構成する方法

旧試作のソースを継ぎ足さず、上記の視覚的長所を新構造上で再実装する。

## 6. 新構造として置き換える要素

| 旧試作 | 新構造 |
|---|---|
| カメラ、道、地形が別々の曲線 | 弧長正規化した一本のワールドスプラインと共通評価関数 |
| 固定幅に近い明るい道 | `trailWidth(s)`と符号付き距離による連続縮幅、非周期のedge breakup |
| 固定カメラ高 | `terrainHeight(cameraX,cameraZ)+eyeHeight` |
| 森内部中心 | 草原、林縁、成木通過、森内部、小川の6コマ |
| 終端ループ | 10秒で0→1へ進み停止 |
| 文進捗相当で位置を戻す余地 | ステージ全体の単調増加`journeyProgress`、文区切りで位置保持 |
| 検査手段なし | s直接指定、植生非表示、中心線・幅・カメラ・先読み・橋表示 |

## 7. 橋手前の構図

簡易上面図（上が対岸）:

```text
             明るい抜け・遠山
                  △
             対岸の細道
                 ║
      低木     ┌─╫─┐      高木は外側
~~~~~~~~~~~~~~~│橋板│~~~~~~~~~~~~~~~  小川は進行方向を横断
 苔岩・シダ    └─╫─┘    苔岩・シダ
                 ║
          1.6mの取り付き
              ↗  │
          カメラ ●   水際から2.5〜4m
```

- 橋の中心と向きはルート終端フレームから求める。
- 水路はルート接線にほぼ直交させるが、画面上は完全水平を避けて5〜15度振る。
- 橋板は5〜8枚の隙間を読める間隔にし、一枚の台形へ連結して見えないようにする。
- 橋の両側に水面を見せ、手前岸・対岸の地面で水面の輪郭を挟む。
- 対岸の道中心は橋中心と一致し、明るい抜けまで続ける。
- s=.85以降は高木を外側へ逃がし、橋中心から左右3m以内へ太い幹・大樹冠を置かない。

## 8. 実装・承認順序

1. 本書をレビューし、6コマの構図と密度帯を承認する。
2. 位置だけを示す上面デバッグで、木・橋・道・カメラの配置を確認する。
3. 一人称6コマを撮影し、本書の合格条件とスケッチへ横並びで照合する。
4. 不合格コマだけを配置調整し、全画像を同じ版で再撮影する。
5. 10秒停止、文区切り保持、スクラブ再現性、コンソール、buildを確認する。
6. グレーボックス承認後にのみ、品質版のモデルと水彩表現へ進む。

手順3では、各6コマについて「承認済みスケッチ」「同じ `s` の実装画像」「合格条件の判定」を一つの比較表へ並べる。数値条件を満たしても、承認済みスケッチの構図意図と明らかに異なる場合は不合格とする。
