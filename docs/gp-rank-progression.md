# GP・探検家グレード進行設計

## 目的

GPを一時的な上手さではなく、十分な練習を積み重ねた目安にする。低学年の子どもが小さな達成を感じられる一方、数問だけで高グレードへ進まない進行を目指す。

## 現状分析

従来は1問につき約675〜1,250 GP、標準的な正確入力で約1,000 GPを得られた。最初のグレードは8,000 GPなので約8問、最高グレードも約400問で到達できる。通常の発見は120〜150 GP、レア発見は800〜1,000 GPあり、偶然の発見1回が問題1問分に近いこともインフレ源だった。

| 要素 | 従来 | 改定後 |
| --- | ---: | ---: |
| 1問の基本GP | 675〜1,250 | 0〜120 |
| 正確さの比重 | 50% | 70%（ミスを二乗で減点） |
| 速度の比重 | 50%・最低保証あり | 30%・基準速度で上限 |
| 丁寧な入力ボーナス | なし | 正確さ95%以上かつ基準速度70%以上で20 |
| 通常のお宝 / いきもの | 120 / 150 | 15 / 20 |
| レアのお宝 / いきもの | 800 / 1,000 | 60 / 80 |

速度は基準を超えても加点しない。正確さ80%・基準速度なら69 GP、正確さ100%・基準速度なら120 GPとなり、速さだけでなく丁寧さを優先する。

## グレードと目標到達ペース

試算は「平均105 GP/問、1日20問、発見込みで約2,200 GP/日」の継続練習を基準とする。日数は目安であり、正確さや練習量で前後する。

| グレード | 必要GP | 約何問 | 目安 |
| --- | ---: | ---: | ---: |
| たまご探検家 | 0 | 0 | 開始時 |
| ひよこ探検家 | 5,000 | 48問 | 2〜3日 |
| ブロンズ探検家 | 20,000 | 191問 | 約9日 |
| シルバー探検家 | 50,000 | 477問 | 約23日 |
| ゴールド探検家 | 120,000 | 1,143問 | 約55日 |
| 伝説の探検家 | 300,000 | 2,858問 | 約4〜5か月 |

1日5問なら最高位は約1年半の長期目標になる。最初の昇格も約10日で、毎日の小目標やステージクリアが短期の達成感を補う。

## 複合ゲートの判断

異なる問題数、コース達成数、正確さ、継続日数を昇格の必須条件にすると反復だけの昇格を確実に防げる。一方、現時点ではステージ内コース構造と問題IDを変更中で、必須条件にすると正しく練習している子が説明のないまま昇格できない危険がある。そのため今回の安全な改定ではGP単位・加点比率・閾値を先に正常化し、既存の問題統計と日次活動は変更しない。

次段階では、表示できる条件として「累計完了問題数」「異なる問題の完了数」「正確さ90%以上の問題数」「練習日数」を記録し、子どもが不足条件を理解できるUIと同時に導入する。単純な隠しゲートにはしない。

## 保存データへの影響

ステージ内区間対応と同時に保存形式をschema v2へ更新する。従来GPは加点単位が約10倍であり、そのまま新閾値へ適用すると即時昇格になるため、schema v1以前からの移行時は `lifetime`、`courseBest`、`coursePlays` を0へ戻す。問題別統計、キー統計、発見コレクションは学習記録として保持する。schema v2で新しいGPを貯めた後は再読込しても保持する。

## 受入基準

- 正確さ100%・基準速度の1問は120 GP以下である。
- 正確さ80%では、基準速度でも70 GP以下である。
- 基準速度を超える連打で速度GPが増え続けない。
- 通常発見は1問上限の6分の1以下、レア発見も1問上限未満である。
- 平均的な練習で最高位まで少なくとも2,500問以上かかる。
- ランク案内と発見画面の数値は定義値から自動表示される。
- テスト、lint、production buildが通る。
