# ことば島 球体世界ワールドマップ正本

最終更新: 2026-08-10
状態: 座標・投影・画像制作前の正本
制作ゲート: 座標表とpromptのレビュー後にのみ地図画像を生成する

## 1. 結論

ことば島は球体世界上の一つの大島であり、ゲームの一本道は球面に沿う連続routeである。画面に出す平面地図は独立した架空配置ではなく、この球体座標を正距円筒図法または局所正距方位図法で投影した図とする。

旅は一章ごとに島を一周するが、惑星を一周せず、約18×14kmの島内を巡る。章ごとに全く同じ線を再生せず、同じ地域内の隣接する回廊を通る。雲上遺跡は別空間でなく、古代樹上空の同緯度経度に高度を持つ地形である。極越え、日付変更線横断、数千kmの瞬間移動はない。

## 2. 座標系

- 惑星基準: 半径`R = 6371km`相当の球体。描画時は任意縮尺へ変換可。
- 島中心: 緯度`12.025°N`、経度`142.000°E`。これは架空世界の内部座標で、現実の地名を意味しない。
- 局所範囲: 緯度`11.955〜12.105°N`、経度`141.925〜142.085°E`。
- 高度: 地表`0〜1.25km`、雲上遺跡`1.65〜2.05km`。海面を`0km`とする。
- 方向: 地図上の北を上、東を右。基本旅程は南東草原から北西寄りの森・山へ進み、南西の入り江、中央の古代樹、上空遺跡を経て南東草原へ戻る反時計回り。
- Three.js変換: 球中心を原点とし、緯度`φ`、経度`λ`、高度`h`から `(R+h)[cosφ cosλ, sinφ, cosφ sinλ]` を求める。局所チャンクでは接平面ENUへ変換し、境界で原点をrebasingする。

```ts
type SphericalJourneyPoint = {
  latitudeDeg: number
  longitudeDeg: number
  altitudeKm: number
  worldProgress: number
}
```

カメラとrouteの正本は球面座標であり、平面ENUは現在チャンクを安定描画する派生座標である。原点rebasingでscene、camera、audio、`worldProgress`を再生成しない。

## 6. 平面地図の投影

- UI全島図: 島中心を投影中心とする局所正距方位図法。距離と方向を島内で自然に保つ。
- 制作管理図: 緯度経度格子を見せる正距円筒図法。境界chunkとroute座標の照合用。
- 雲上遺跡: 平面図では古代樹の上へ半透明の高度別insetとして置き、地上の別島に描かない。
- route: Stage 1〜12は実線、13〜36は計画線。章ごとに線種と小さな章番号を変え、色だけに依存しない。
- 平面図上の重なり: 同地域の六レーンは少し離して描くが、実座標以上に大きく引き離さない。

画像生成時は文字・ラベルを画像モデルに描かせず、地形だけ生成して座標準拠のSVG/HTMLオーバーレイで名称とrouteを載せる。

## 8. オーバーレイ制作仕様

生成地形画像の承認後、routeとラベルは決定論的なSVGまたはHTMLで追加する。

- 地表routeは座標表を投影してBezier補間し、Stage境界に番号付き節点を置く。
- 高度区間は二重線または上昇矢印、下降区間は破線階段で表す。色だけに依存しない。
- Stage 1〜12: 太さ4相当の実線。Stage 13〜36: 太さ2相当の計画破線。
- 移動方向: 各Stage中央に一つの小矢印。大量の矢印で地形を隠さない。
- chapter境界: Stage 6/12/18/24/30/36に形の異なる六角節点。
- ラベル: 地形画生成後に日本語ルビ対応のHTML/SVGで追加。画像へ焼き込まない正本も保持する。
