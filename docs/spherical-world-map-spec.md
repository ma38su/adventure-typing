# ことば島 球体世界ワールドマップ正本

最終更新: 2026-08-10

## 1. 結論

ことば島は球体世界上の一つの大島であり、ゲームの一本道は球面に沿う連続routeである。画面に出す平面地図は独立した架空配置ではなく、この球体座標を正距円筒図法または局所正距方位図法で投影した図とする。

島は、活動を終えて侵食が進んだ低緯度の玄武岩質火山島である。北〜北西の弧状山地は旧カルデラ縁と岩脈帯、中央〜南東は緩い溶岩原、南西湾は侵食谷が沈水した地形とする。東北東の卓越風を受ける北東斜面は多雨、南西側は雨陰となり、地形、川、地下水、土壌、植生、暮らしを同じ因果で配置する。

旅は一章ごとに主要流域・外輪山・湾・中央樹を結ぶ巡礼環を通るが、惑星を一周せず、約17×16kmの島内を巡る。章ごとに全く同じ線を再生せず、同じ地域内の隣接する回廊を通る。雲上遺跡は別世界でなく古代樹上空の同緯度経度にある人工・生物構造物であり、自然の山頂ではない。極越え、日付変更線横断、数千kmの瞬間移動はない。

## 2. 座標系

- 惑星基準: 半径`R = 6371km`相当の球体。描画時は任意縮尺へ変換可。
- 島中心: 緯度`12.025°N`、経度`142.000°E`。これは架空世界の内部座標で、現実の地名を意味しない。
- 局所範囲: 緯度`11.955〜12.105°N`、経度`141.925〜142.085°E`。
- 高度: 地表`0〜1.25km`、雲上遺跡`1.65〜2.05km`。海面を`0km`とする。
- 方向: 地図上の北を上、東を右。基本旅程は南東草原から北西寄りの森・山へ進み、南西の入り江、中央の古代樹、上空遺跡を経て南東草原へ戻る反時計回り。
- 気候基調: 東北東の卓越風。北東風上斜面は多雨、南西風下斜面は雨陰だが砂漠化しない。5〜11月を若雨・多雨期、12〜4月を比較的乾く花風期の基調とする。
- Three.js変換: 球中心を原点とし、緯度`φ`、経度`λ`、高度`h`から `(R+h)[cosφ cosλ, sinφ, cosφ sinλ]` を求める。局所チャンクでは接平面ENUへ変換し、境界で原点をrebasingする。

```ts
type SphericalJourneyPoint = {
  latitudeDeg: number
  longitudeDeg: number
  altitudeKm: number
  worldProgress: number
}
```

カメラとrouteの正本は球面座標であり、平面ENUは現在チャンクを安定描画する派生座標である。原点rebasingでscene、camera、audio、`worldProgress`を再生成しない。

### 5.1 唯一のroute距離

座標アンカー間は多くが水平約5〜8km、一章約30〜38km、全六章約190〜220kmになる。これは六章にわたり同じ島の隣接レーンを巡る長い旅として成立する。球面座標から算出する`routeDistanceKm`を、地図routeと3D world routeの唯一の距離正本にする。

- 地図と3Dでroute長、地形曲率、Stage境界位置を変えない。
- 空間短縮、途中skip、teleportを行わず、chunk streamingと原点rebasingで全距離を連続保持する。
- 見える前進速度を不自然に上げない。距離、六コマanchor、発見・境界beatから各Stage 18〜60問・可変courseを見積もり、短文を追加する。現実の徒歩時間そのものは採点条件にしない。
- `worldProgress`は物語進捗だが、必ず同じ球面route上の位置へ単調写像し、文・コース・Stage境界で戻さない。
- root–skyの大きな標高差は人工・生物構造物の螺旋上昇路として、同じ距離正本上で通過する。
- 制作データは`routeDistanceKm`、標高差、`watershedId`、`climateZoneId`を持つ。

## 6. 平面地図の投影

- UI全島図: 島中心を投影中心とする局所正距方位図法。距離と方向を島内で自然に保つ。
- 制作管理図: 緯度経度格子を見せる正距円筒図法。境界chunkとroute座標の照合用。
- 雲上遺跡: 平面図では古代樹の上へ半透明の高度別insetとして置き、地上の別島に描かない。
- route: Stage 1〜12は実線、13〜36は計画線。章ごとに線種と小さな章番号を変え、色だけに依存しない。
- 平面図上の重なり: 同地域の六レーンは少し離して描くが、実座標以上に大きく引き離さない。

## 8. オーバーレイ制作仕様

生成地形画像の承認後、routeとラベルは決定論的なSVGまたはHTMLで追加する。

- 地表routeは座標表を投影してBezier補間し、Stage境界に番号付き節点を置く。
- 高度区間は二重線または上昇矢印、下降区間は破線階段で表す。色だけに依存しない。
- Stage 1〜12: 太さ4相当の実線。Stage 13〜36: 太さ2相当の計画破線。
- 移動方向: 各Stage中央に一つの小矢印。大量の矢印で地形を隠さない。
- chapter境界: Stage 6/12/18/24/30/36に形の異なる六角節点。
- ラベル: 地形画生成後に日本語ルビ対応のHTML/SVGで追加。画像へ焼き込まない正本も保持する。

## 9. 整合チェック

- [ ] 全Stageの終了座標が次Stageの開始座標または同一共有chunk内の連続routeである。
- [ ] 山川が山→森→入り江へ流れ、上流下流が逆転しない。
- [ ] 弧状分水嶺を川が横切らず、三支流の合流と湧水に地質上の理由がある。
- [ ] 河口湿地→海草藻場→白砂ポケット浜・外湾裾礁が濁りと水深に沿って分かれる。
- [ ] 低地常緑・半常緑林→山地雲霧林→風衝尾根が標高・風上風下に沿って連続する。
- [ ] 古代樹と雲上遺跡が同じ緯度経度帯で高度接続する。
- [ ] 各章の草原復帰に物理下降路があり、ワープがない。
- [ ] 六章のレーン差が350m以内を基本とし、同じ土地の再訪に見える。
- [ ] Stage 1〜12実装線とStage 13〜36計画線を視覚的に区別する。
- [ ] 平面図とグローブ図が同じ地形方位を持つ。
- [ ] 集落・建材・生業が風、雨、高潮、地質に適応し、巨大都市アイコンで地域を区別していない。
- [ ] 動物に定着種・広域利用種・人と暮らす個体・来訪者・文化的呼称の分類がある。
- [ ] 地図routeと3D world routeが同じ`routeDistanceKm`を参照し、空間短縮・途中skip・teleportがない。
- [ ] 地図画像生成前に本書の座標と地理骨格をレビューする。
