# 世界樹に依存しない火山島への地理改定

## 決定

ことば島は、世界樹・古代樹を地理、水循環、移動、空への接続の成立条件にしない。島の骨格は古い玄武岩質火山島として完結させる。

既存資料に残る「中央古代樹」「根水路」「古代樹上空の遺跡」は旧案であり、以後の島地形・周遊route・3D制作ではこの文書を優先する。通常サイズの古木や樹林は置けるが、島を支える一本の巨大樹にはしない。

## 置換対応

| 旧要素 | 新しい地理要素 | 成立理由 |
|---|---|---|
| 古代樹の外縁 | 玄武岩柱の盆地 | 古い火口底の侵食残丘と柱状節理 |
| 根泉の谷 | 湧水の谷 | 溶岩流境界、岩脈、古土壌に堰き止められた地下水 |
| 根水路 | 溶岩洞・破砕帯・湧水線 | 火山島の透水層と不透水層 |
| 古代樹が支える上空施設 | 北西高地の観測跡または終盤専用の人工構造 | 必要性を物語側で再検討する |
| 中央の巨大樹冠 | カルデラ縁、風見尾根、海岸線 | 複数の自然ランドマークで方位を取る |

## 地形とroute

- 北西のカルデラ縁と最高峰は残し、島の火山起源を遠景で読ませる。
- routeは高峰へ直登せず、海岸段丘、河川谷、鞍部、尾根の肩、火口盆地を結ぶ。
- 高低差は消さない。登りは等高線に沿う折返しへ分解し、前後に平坦な休息区間と眺望を置く。
- 開けた場所と閉じた場所、湿潤地と雨陰、海辺と高地を交互にし、一つの景観を延々と続けない。
- 全島LODとgameplay-near LODは同じ地理座標・標高正本を使う。近景LODだけ別の山を作らない。

## 周遊デモでの最初の適用

`islandGrandTour.ts` の閉路は、南東草原、東の低地林、北東多雨林、北西カルデラ縁、西の雨陰尾根、南西河口、白砂浜、湧水谷、玄武岩柱盆地、南岸集落を巡る。中央の巨大樹モデルは置かない。

この閉路は物語順ではなく、島の地形と景観リズムを検証する基準routeである。正式ステージは、この地理骨格上に物語、発見、動物、BGMの意味区間を後から割り当てる。
