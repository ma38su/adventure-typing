# 三人称冒険者・プリプロダクション

更新: 2026-08-10
正本: `docs/third-person-adventurer-design.md`

## `third-person-adventurer-turnaround-v1.png`

OpenAIの組み込み画像生成で作成した三面図の比較用v1。正式モデル・配信素材ではない。

合格点:

- 後方から髪、襟、上着裾、斜め掛け鞄、靴が読める。
- 青緑、生成り、土色、琥珀色の意味配色が水彩トゥーン方向に合う。
- 帽子、武器、長いマントがなく、景観と発見予兆を遮らない。
- 鞄と髪の輪郭が肩・肘・膝の可動域へ大きく干渉しない。

v2での修正:

- 現状は約4頭身寄りなので、脚と胴を少し伸ばし4.5頭身へ近づける。
- 正面の目・鼻・口をもう一段簡略化し、遠景で顔へ依存しない。
- 側面も前後と同じrig用Aポーズとし、腕を胴から少し離す。
- 頭頂、肩、肘、腰、膝、接地線を三面で厳密に揃える。

最終promptの要約: 4.5頭身の中性的な子ども冒険者、正面・真横・背面、Aポーズ、短い上着・裾絞りパンツ・短靴・小型斜め掛け鞄、簡略日本画×透明水彩、文字と背景なし。

## `third-person-adventurer-turnaround-v2.png`

v1を編集元に、3Dモデリングへ渡しやすい比率とポーズへ修正した方向確認用v2。OpenAIの組み込み画像生成を使用し、正式モデル・配信素材にはまだしない。

v1からの改善:

- 胴と脚を伸ばし、子どもらしさを残した約4.5頭身へ近づけた。
- 正面・側面・背面で接地線、膝、腰、肩、頭頂の高さが概ね揃った。
- 全ビューで腕を胴から離し、肩・肘・手首のリグとウェイトを設計しやすくした。
- 側面を三四分割ではなく直交に近い真横へ修正した。
- 鞄、上着裾、靴、配色はv1の同一人物として維持した。

残る確認点:

- 側面の腕が重なって一本に見えるため、正式モデリング時は左右腕を同じ骨格寸法から作る。
- 鞄のストラップは肩・胸の変形へ追従させず、別メッシュまたは補助骨を候補にする。
- 画像の水平ガイドは厳密な寸法図ではないため、Blender側で共通骨格寸法を数値固定する。
- この三面図の承認後にのみ、低〜中ポリゴンのgrey model、rig、walk clipの順で試作する。

最終promptの要約: v1の人物・衣装・水彩配色を保持し、約4.5頭身、三面同一縮尺、全身Aポーズ、真横の直交側面、関節と接地線を整列、顔をやや簡略化、交差しにくい鞄配置へ編集。

## `third-person-adventurer-girl-turnaround-v1.png`

正式3D化の優先pilot候補。中性的なv2と同じ共通骨格、旅装、配色、4.5頭身を保ち、実用的な短いボブと小さな片側結びで女の子として判別できるようにした。

採用意図:

- 女の子版を先にgrey model、rig、walkの検証へ進める。
- 長髪・スカート・大きな装飾を避け、歩行、鞄、襟、発見演出との干渉を抑える。
- 顔の細部ではなく、丸いボブ、小さな琥珀色の髪留め、葉形の上着留めで後方視点でも識別する。
- 中性的なv2と同じ骨格寸法・motion clipを共有できる設計とする。

画像QA:

- 正面・真横・背面が同一縮尺のAポーズで、主要関節と接地線は概ね整列している。
- 髪は肩より上に収まり、腕・鞄・上着裾の可動域を塞いでいない。
- 側面の鞄と前後ビューの鞄位置は概ね一貫している。
- 側面では左右腕が重なるため、正式モデルは三面図の輪郭をトレースせず共通skeletonから左右対称に構築する。

最終promptの要約: 中性的v2を編集元に、同じ世界観・旅装・4.5頭身・共通rigを維持した女の子版。顎までの短いボブ＋小さな片側結び、琥珀色の髪留めと葉形留め、三面同一Aポーズ、長髪・スカート・装飾過多なし。
